Privacy Policy

Application Package: com.udittandon.debtfree • Last Updated: July 21, 2026 • Effective Version: v1.1.3
Key Privacy Pledge: DebtFreeIn operates on a zero data monetization policy. We do not sell, rent, or trade your personal or financial data to advertisers, data brokers, or third parties. All sensitive API credentials remain stored locally on your device in hardware-backed encrypted storage.

1. Overview & Information We Collect

DebtFreeIn ("Application", "we", "our") provides algorithmic trading execution, cognitive paper trading simulation, and debt management utilities. To provide these functionalities, the application handles specific data types:

  • Firebase Authentication & User Account Data: Your email address and unique Firebase User Identifier (UID) used strictly for biometric vault syncing and authorized device identification.
  • Broker API Credentials (Upstox): Upstox API keys, client secrets, and OAuth authorization tokens provided directly by you.
  • Financial Telemetry & Trade Logs: Real-time session metrics (PnL, active tripwire status, daily round-trip counts) synced to your private Firebase Firestore instance for cross-device monitoring.
  • SMS Transaction Logs (Optional): Transaction notifications parsed locally on-device to track credit card expense balances. Raw SMS text never leaves your device.

2. Local Storage & Encryption Architecture

We prioritize hardware-backed encryption to protect your sensitive credentials:

  • Upstox API keys and secret tokens are stored using Android's EncryptedSharedPreferences backed by the AndroidKeyStore system.
  • Sensitive financial data (credit card limits, debt metrics, and virtual ledgers) is persisted in a local Room SQLite database encrypted on disk.
  • Biometric prompts (Fingerprint / Face Unlock / Device PIN) gate local access to the application via Android Jetpack Biometric API.

3. Third-Party API Integrations

A. Upstox API Integration

DebtFreeIn interfaces directly with the official Upstox V3 API endpoints for order placement, cancelation, and OAuth 2.0 authorization token exchanges. All network requests are routed over TLS 1.3 encrypted HTTPS. Upstox credentials are used exclusively to execute actions explicitly requested by you or governed by your active risk parameters.

B. Firebase Services (Google Cloud)

We utilize Firebase Authentication, Cloud Firestore, and Firebase Cloud Messaging (FCM) for user authentication, failover device telemetry, and real-time risk alert notifications. All Firestore collections are protected by strict security rules limiting access exclusively to your authenticated Firebase UID.

C. Google Gemini Generative AI SDK

If enabled by you, non-identifiable numerical summaries (such as anonymized trade volume, gross PnL, or aggregated debt figures) are sent to the Gemini API solely for generating financial advice reports and trade post-mortems. No personally identifiable information (PII) is submitted to Gemini.

4. Data Retention & User Rights

You maintain complete control over your data at all times:

  • Data Erasure: You can clear your API credentials and local database at any time from the app Settings page or by clearing application storage in Android settings.
  • Account Deletion: Deleting your account will immediately remove all associated Firestore telemetry documents and FCM tokens from our Firebase cloud instance.

5. Compliance with Google Play Developer Policies

This Application strictly adheres to the Google Play Developer Distribution Agreement and User Data policies, including target SDK 35 runtime permissions, transparent foreground service notifications, and strict separation of sensitive scopes.
